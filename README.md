# ARC Requests

A [Chickadee Bandit](https://chickadeebandit.com/app-library/architectural-review) app.

Homeowners submit modification requests for ARC committee review. Committee votes, issues decisions with written rationale, and tracks status to resolution.

## Features

- Homeowners submit requests with supporting documents.
- Committee votes.
- Decisions with written rationale.
- Status tracked to resolution.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-architectural-review/releases/latest/download/bundle.json
```
